# requirements.txt: every Python package in the project's virtual environment, at the exact
# version that was installed and working on 2026-11-18 (Python 3.12.3). Ruling R24.
# psycopg was added on 2026-11-20 (leg C2), with pytest run after the install.
# The five web packages were added on 2026-11-24 (leg C4), with pytest run after the install. No package that was already here changed version.
#
# Why exact versions ("pins"): `pip install paramiko` today gives a newer paramiko that can no
# longer talk to the Duval Clerk's server. A pin means a rebuilt environment behaves like the
# one the code was tested in.
#
# Rebuild the environment from the VS Code terminal:
#     cd ~/datum
#     python3.12 -m venv .venv            # create an empty virtual environment in .venv/
#     source .venv/bin/activate           # switch this terminal to it
#     pip install -r requirements.txt     # install exactly what is listed here
#
# When you add or upgrade a package: install it, run `pytest`, then refresh this file from
# `pip freeze` and keep the comments.
#
# NOT here, because they are not Python packages in this environment: dbt (2.0.12) and the
# Snowflake CLI `snow` (3.30.0) are standalone programs in ~/.local/bin.
